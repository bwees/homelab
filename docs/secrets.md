# Secrets

Infisical Cloud holds every secret. There are two projects:

- `homelab` (created by tofu): what the clusters read through the `infisical` ClusterSecretStore.
  Each cluster has its own read-only identity.
- `opentofu` (created by hand): tofu's provider credentials. Cluster identities have no access.

Folders and tofu-generated secrets are declared in [secrets.tf](../tofu/config/secrets.tf).
Hand-entered secrets are edited in the Infisical UI.

## Naming

| Thing               | Convention                               | Example                             |
| ------------------- | ---------------------------------------- | ----------------------------------- |
| Infisical folder    | `/<app>`, the app that reads it          | `/hermes`, `/cert-manager`          |
| Per-cluster folder  | `/<app>/<cluster>`                       | `/github-webhook/hail-mary`         |
| Per-purpose folder  | `/<app>/<purpose>`                       | `/volsync/b2`                       |
| Secret name         | UPPER_SNAKE_CASE, names the value        | `DISCORD_BOT_TOKEN`, `PASSWORD`     |
| ExternalSecret      | `<app>`, or `<app>-<purpose>` for extras | `zulu-notifyd`, `zulu-notifyd-apns` |
| Kubernetes Secret   | `<app>-secret`, or `<app>-<purpose>`     | `hermes-secret`, `bind9-tsig`       |

- A secret shared between apps lives under the app that owns it. `external-dns-bind` reads `/bind9`.
- Secret names describe the value, not the variable an app expects. The ExternalSecret template
  does that mapping.
- Charts that hard-code a Secret name keep it (`operator-oauth` for the Tailscale operator).
- Tokens used outside the clusters get a folder named after where they are used: `/unifi-ddns`.

An ExternalSecret reads one folder:

```yaml
dataFrom:
  - find:
      path: /hermes
```

## Adding a secret

- Generated by tofu: add it under `secrets` in `secrets.tf`.
- Entered by hand: add the folder under `folders` in `secrets.tf`, apply, then enter the value in
  the UI.

## New cluster

`mise run bootstrap <host>` seeds `secrets/infisical-universal-auth` from tofu's
`infisical_cluster_credentials` output. Add the cluster to `local.clusters` and apply first.
